Computed

The computed function takes a function and an array of model or signal dependencies. When a change event is fired on any of the dependencies the computed updates its value.

The signals are updated using the change event of the input, so updates are applied when the input loses focus. The Javascript for this component looks like this:

import { directives } from '../src/reactive/index.js'
import { computed, signal } from '../src/signals/index.js'

const name = signal('John')
const familyName = signal('Smith')

directives.load(document.getElementById('mount'), {
	name,
	familyName,
	fullName: computed(() => `${name} ${familyName}`, [name, familyName]),
})

The HTML code looks like this:

<div id="mount">
	<p>Full Name: <strong data-q-text="fullName"></strong></p>
	<p>Name: <em data-q-text="name"></em></p>
	<p>Family Name: <em data-q-text="familyName"></em></p>
	<div>
		<label>Name <input type="text" data-q-input="name" /></label>
	</div>
	<div>
		<label>Family Name <input type="text" data-q-input="familyName" /></label>
	</div>
</div>

The computed function returns an instance of the Computed class which extends Signal and has the same interface:

value (getter / setter)
The value of the signal. Setting a new value fires a ChangeEvent event.
on(fn) (function)
Provide a function (fn) which subscribes to changes to the value property. Returns a function which removes the subscription when called.

The function passed to computed receives all dependencies as arguments in the order they're declared in the array.
