Signals

Signals are the core to reactivity. A signal takes a value and notifies any subscribers when the value changes.

The value of planet is notified of the change when the text input loses focus. This update is propagated to the displayed text. The Javascript looks like this:

import { directives } from '../src/reactive/index.js'
import { signal } from '../src/signals/index.js'

directives.load(document.getElementById('mount'), {
	planet: signal('Earth'),

	change(_evt, context) {
		this.planet.value = context.node.innerText
	},
})

The HTML code looks like this:

<div id="mount">
	<p><em data-q-text="planet"></em></p>
	<p><strong data-q-text="planet"></strong></p>
	<div>
		<button data-q-click="change">Mercury</button>
		<button data-q-click="change">Venus</button>
		<button data-q-click="change">Earth</button>
		<button data-q-click="change">Mars</button>
		<button data-q-click="change">Saturn</button>
	</div>
</div>

The signal function returns an instance of the Signal class which has the following interface:

value (getter / setter)
The value of the signal. Setting a new value fires a ChangeEvent event.
on(fn) (function)
Provide a function (fn) which subscribes to changes to the value property. Returns a function which removes the subscription when called.

Signals are designed for use with simple values such as string, boolean, or number. They don't notify subscribers on changes to list elements or object properties. They will notifiy subscribers if an array or object is replaced with a new array or object.

Signal implements valueOf and toString methods using their underlying value so things like signal(5) + 5 // 10 works as expected.
