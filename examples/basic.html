A Basic Component

This component does very little except display data! It also responds to function calls but none of its data is reactive so the text will never change.

It does show the basic principals of how a component is constructed. The script block looks like this:

import { directives } from '../src/reactive/index.js'

directives.load(document.getElementById('mount'), {
	planet: 'Earth',

	show() {
		alert(this.planet)

		this.planet = 'Mars'

		alert(this.planet)
	},
})

The HTML code looks like this:

<div id="mount">
	<p><em data-q-text="planet"></em></p>
	<p><strong data-q-text="planet"></strong></p>
	<button data-q-click="show">Click me</button>
</div>

The HTML interacts with the Javascript through the data-q-* attributes. The q part is customisable using the directives.setPrefix method but is really just a short identifier to distinguish data attributes that the system cares about. I think of the library as being quick for the developer, hence q.

The data-q-text attribute displays the value of the text property of the data object using the innerText property of the element. It watches for changes to text and when that happens it sets the innerText property again.

The data-q-click attribute looks for a clear function on the root object and calls it when an click event is fired. In this case the clear function sets the text property to an empty string which updates the input element and the two display elements.
