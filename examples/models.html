Models

The model function takes a plain Javascript object and converts all of its properties to signals.

Distance from the sun (AU):

Any change to properties of planet notify the text to update through the same change event that a signal uses. Individual properties can also be subscribed to, either directly through planet.name.on(fn) or by providing a property to the on method of the model: planet.on(fn, 'name'). The Javascript for this component looks like this:

import { directives } from '../src/reactive/index.js'
import { model } from '../src/signals/index.js'
import { notNull } from '../src/utils/assert.js'

const planets = {
	'Mercury': 0.387,
	'Venus': 0.723,
	'Earth': 1,
	'Mars': 1.5,
	'Saturn': 9.6,
}

directives.load(document.getElementById('mount'), {
	planet: model({
		name: 'Earth',
		distanceAU: 1,
	}),

	change(_evt, context) {
		const name = context.node.innerText
		const distance = planets[name] ?? null

		if(notNull(distance)) {
			this.planet.name.value = context.node.innerText
			this.planet.distanceAU.value = distance
		}
	},
})

The HTML code looks like this:

<div id="mount">
	<p>Planet name: <strong data-q-text="planet.name"></strong></p>
	<p>Distance from the sun (AU): <strong data-q-text="planet.distanceAU"></strong></p>
	<div>
		<button data-q-click="change">Mercury</button>
		<button data-q-click="change">Venus</button>
		<button data-q-click="change">Earth</button>
		<button data-q-click="change">Mars</button>
		<button data-q-click="change">Saturn</button>
	</div>
</div>

Note the data-q-text attributes are using standard dot notation to access the properties of the planet object.

The model function returns an instance of the Model class which has the following interface:

[property]
Any property provided to the model function is converted to a signal and used as a property of the model. Setting a new value on a property fires a ChangeEvent event for the model and a PropertyEvent for the speccific property which changed.
on(fn) (function, property = undefined)
Provide a function (fn) which subscribes to any changes to the model. If property is provided, subscribe solely to changes to that property. Returns a function which removes the subscription when called.
